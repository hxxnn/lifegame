# 라이프 RPG v2 개선 설계

작성일: 2026-11-07 · 상태: 대화에서 승인됨(사용자 "좋아 진행해줘"), 이 문서는 기록용

실사용 관점 점검에서 나온 개선 8건과 사소한 수정. 기본 설계(`2026-11-07-life-rpg-design.md`)에 더해 적용한다.

## 데이터 (저장 버전 2)
- `PlayerState`에 `settings.dayStartHour`(0~6, 기본 0), `backup.{lastAt,nudgedAt}`(날짜 또는 null), `reportSeenWeek`(주 ID 또는 null)를 추가한다. `DayRecord.swaps`(선택, 교체 횟수).
- v1 저장은 열 때 기본값으로 자동 업그레이드한다(진행 상황 유지).

## 기능
1. **지난주 결산**: 새 주 첫 접속 시 홈 상단 카드(완료/전체, 클리어율, 스탯별 경험치, 전부 완료한 날, 이번 주 테마가 정해진 이유). 닫으면 `reportSeenWeek` 기록. 캐릭터 탭에 최근 8주 기록. 홈에 "어제 n/m" 한 줄.
2. **홈 첫 화면**: 캐릭터 소형 가로 배치, 주간 배너 접이식, 홈에서는 상단 바 진행률 칩 숨김.
3. **퀘스트 교체**: 하루 2번(`BALANCE.dailySwaps`). 같은 스탯·같은 티어, 오늘 목록과 어제 퀘스트 제외(후보 부족 시 어제 제외 완화). 완료·고정 습관은 불가. 후보가 없으면 버튼 비활성.
4. **백업 안내**: 누적 클리어 10개 이상 + 마지막 백업 7일 이상(또는 없음) + 오늘 아직 안내 안 함 → 홈 안내. 내보내기 시 `lastAt` 기록.
5. **하루 시작 시간**: 설정 0~6시. 논리 날짜 = `now - startHour`. 날/주 정산, 월요일 변경 규칙 모두 논리 날짜 기준.
6. **도감**: 잠금 항목은 종류(장비·칭호·배경·캐릭터)만, 다음 항목 1개는 이름까지 공개. 캐릭터 해금 알림에 "월요일에 바꿀 수 있어요".
7. **공유 카드 미리보기**: 공유 탭에 PNG 미리보기.
8. **온보딩**: 잠긴 캐릭터 접기, 스탯 한 줄 설명.
9. **사소한 수정**: 온보딩 후/탭 전환 시 맨 위로, 온보딩에서도 저장 안내 배너, 가져오기 후 닉네임 갱신, PNG 저장 실패 안내와 `revokeObjectURL` 지연, `/index.html` 공유 링크, 공유 링크 `cleared` 상한(1,000,000), 비교 화면에 칭호·주력 스탯, 알림 최대 2건 + "외 n건".

제외: 퀘스트 풀 내용 보강.
